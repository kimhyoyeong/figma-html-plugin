# Figma HTML Export (figma-html-plugin)

Figma 시안을 **반응형 HTML/CSS 초안**으로 변환하고,  
AI를 활용해 **heading 구조와 이미지 alt를 자동 개선하는** Figma 플러그인입니다.

---

## 1. 개요

AP 주요 업무인 **헤라 라이브러리 페이지**, **설화수 커버 페이지** 제작을 위해 개발된 Figma 플러그인입니다.

해당 업무는 일반적으로 **PC·모바일 두 벌의 디자인을 각각 작업한 뒤 반응형으로 구현**하는 방식으로 진행됩니다.  
이 과정에서 디자인을 코드로 옮기는 작업은 수작업으로 이루어지며, **최소 약 2일 이상의 공수**가 소요됩니다.

본 플러그인은 이러한 초기 퍼블리싱 작업을 자동화하여,  
작업 시간을 단축하고 전반적인 업무 효율을 향상시키기 위해 제작되었습니다.

---

## 2. 주요 기능

- Figma 시안을 **HTML/CSS 초안**과 **이미지 에셋**으로 변환
- **레이어 구조 기반 마크업** (레이어 탭에서 `dataTree` 등으로 트리·속성 확인)
- 타이포·이미지 **규칙 기반** 변환, 레이어 이름 **`code-*`** 규칙 (`code-btn`, `code-slide` 등)
- **AI 기반** heading / alt 제안 및 반영 (코드 탭에서 선택적으로 실행)

---

## 3. 사용 방법

Figma에서 플러그인을 임포트한 후,  
ROOT에 해당하는 PC / 모바일 프레임을 선택하고 **분석**을 실행합니다.

### 3.1 레이어 탭

- 레이어 트리 기반 구조 확인
- 각 노드 속성 및 구성 정보 확인

### 3.2 코드 / AI

- 생성된 HTML/CSS 코드 확인
- AI 분석: **생성된 HTML/CSS**와, 비전 입력용 **JPEG**(비용 최적화를 위해 축소·인코딩된 이미지 사용)를 함께 보내 heading 구조·이미지 alt 등을 제안하고, 즉시 반영 가능
- **EXPORT_ZIP 버튼**을 통해 HTML + 이미지 다운로드

### 3.3 미리보기

- PC / 모바일 화면 확인
- 결과물 1차 검증

---

## 4. 동작 구조 (핵심 로직 요약)

### 4.1 분석 및 입력

- ROOT 1개 → 단일(PC 기준) 분석
- 가로가 큰 프레임을 PC, 작은 프레임을 모바일로 자동 판단
- 프로젝트명·국가 코드 등 → 이미지 파일명 등에 반영

### 4.2 레이어 인스펙트

- 섹션 단위 트리 요약, UI로 `dataTree` 전달 (전체 씬 JSON 덤프와는 별개)

### 4.3 레이아웃 처리

- Auto Layout → flex 변환
- 절대 배치 → CSS 변수 등으로 위치·크기 (`--ap-left` 등)

### 4.4 레이어 이름 규칙 (`code-*`)

- `code-btn`, `code-slide`, `code-video`, `code-raster` 등 → 각 이름에 맞는 마크업·export 동작

### 4.5 HTML/CSS 생성

- 섹션 단위 구조 (`ap-section--01` …)
- 스타일 지연 삽입, Swiper용 마크업·스크립트 생성 (CDN 링크는 주로 미리보기 UI)

### 4.6 타이포 처리

- CSS 변수 기반 (`--ap-fs`, `--ap-lh` 등)
- 줄간 비율·스냅, PC/MO 차이만 `@media` 등에 반영하는 경로

### 4.7 이미지 처리

- export·파일 생성, **PC / 모바일 간 이미지 매칭** (`sourceNodeId`, 이름·순서 매칭)
- 미리보기용 썸네일 vs ZIP용 고해상도 구분
- 파일명 규칙: `page_{프로젝트}_sec{섹션}_img…` 형태

### 4.8 PC / 모바일 처리

- 섹션별 구조 비교 → 같으면 **한 HTML + `@media`**, 다르면 **pc-only / mo-only** 분리
- 스타일 병합과 ZIP 파일명 짝 맞추기는 **별도 단계**

## 5. AI 활용 방식

| 항목 | 설명 |
|------|------|
| 위치 | 코드 탭 (검수 / 반영) |
| 입력 | 생성된 HTML/CSS + 비전용 **JPEG**(원본 고해상도 대신 축소·인코딩된 이미지 사용) |
| 출력 | JSON 제안 (이슈, alt, 헤딩 등). Gemini는 구조화 스키마 |
| 반영 | UI에서 HTML 문자열 패치 |

### 사용 모델 (UI에서 선택)

- GPT-4o, GPT-4o-mini
- Gemini 2.5 Flash

### 역할

AI는 생성된 HTML 결과물을 기반으로 퍼블리싱 품질을 검수하고 개선하는 역할을 수행합니다.

- 이미지(JPEG)를 함께 분석하여, 제품 사용 맥락과 시각 정보를 반영한 alt 텍스트 제안
- 텍스트 구조를 기반으로 섹션별 주요 타이틀을 판단하고, 적절한 heading 구조 제안
- SEO, 접근성, 시맨틱 기준에서 문제를 검수하고 개선 방향 제시

이를 통해 퍼블리싱 과정에서 발생하는 수작업 검수 비용을 줄이고,
일관된 품질의 결과물을 빠르게 생성할 수 있습니다.

---

## 6. 주의사항 (디자인 협조)

- 레이어 구조 정리 필수
- PC/MO **트리 구조가 유사할 때** 반응형(`@media`) 출력에 유리
- Auto Layout 사용 권장 (절대 배치 비중이 높을 경우 CSS 구조가 복잡해질 수 있음)
